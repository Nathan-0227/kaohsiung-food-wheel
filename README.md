# kaohsiung-food-wheel

# 🍜 高雄今天吃什麼？

選不出來吃什麼，就交給轉盤吧！先用篩選條件縮小範圍，轉動轉盤隨機決定要吃哪家高雄餐廳，結果會同時顯示在地圖上，並可以一鍵導航。

🔗 **線上試玩**：https://你的帳號.github.io/kaohsiung-food-wheel/

![網站截圖](screenshot.png)

## ✨ 功能

- 🎡 **美食轉盤**：最多顯示 12 家店，超過時隨機抽選，可以按「換一批」
- 🗺️ **互動地圖**：標出所有符合條件的店家，轉完後地圖自動飛到結果位置
- 🔍 **篩選**：可依類型、價位、行政區、距離篩選（同類條件為 OR，不同類為 AND）
- 🙅 **不要這家**：把轉到的店暫時排除並自動再轉，隨時可以還原
- 📍 **離我最近**：定位後顯示距離並可依距離篩選；不在高雄時可以「模擬我在高雄車站」
- ⭐ **口袋名單**：在地圖上點選位置，新增自己的私房店家（存在瀏覽器裡）
- 📱 **RWD**：手機、電腦都能使用，手機優先設計

## 🍱 內建資料

收錄 55 家高雄店家，分布在 6 個行政區：

| 鹽埕 | 新興/前金 | 苓雅 | 三民 | 左營 | 鼓山 |
|---|---|---|---|---|---|

類型包含小吃、飯麵、早餐、火鍋、甜點/飲料、異國料理。資料整理自 2025–2026 年的公開美食報導與米其林必比登名單，價位為約略估計，地圖標記為大略位置。

## 🛠️ 技術

- 單一 `index.html`（HTML + CSS + JavaScript）
- 地圖：[Leaflet](https://leafletjs.com/) + [OpenStreetMap](https://www.openstreetmap.org/)（CARTO 深色底圖），不需要 API key
- 轉盤：HTML Canvas 繪製 + CSS transform 動畫
- 定位：Geolocation API
- 儲存：localStorage
- 部署：GitHub Pages

## 🤖 開發方式

本專案以 Vibe Coding 完成：

1. 先和 AI（Claude）進行四輪需求討論，整理出規格書
2. 依規格書由 AI 協助實作
3. 用自動化瀏覽器測試驗收標準，修正 bug 後部署

討論過程中的重要決策：

- 地圖改用 Leaflet，不用需要金鑰的 Google Maps API
- 店家數從 200 家調整為約 50 家已查證的店家，並保留擴充架構
- 加入「模擬我在高雄車站」功能，讓不在高雄的人也能測試距離功能

## ➕ 新增內建店家

在 `index.html` 的 `STORES_RAW` 陣列加一行即可：

```js
["店名","類型",價位(1-3),"行政區","一句推薦","地址",緯度,經度],
```
